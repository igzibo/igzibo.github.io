Professional Overview

Samia is a Senior SQL Server and Azure Database Administrator with 8+ years of hands-on experience supporting enterprise, mission-critical database environments across retail and high-availability systems. She brings deep expertise in SQL Server 2012–2022 administration, Always On Availability Groups, clustering, replication, database tuning, and cloud migration strategies.

Her background includes managing production, QA, and development systems, automating DBA processes, and leading HA/DR initiatives in large-scale environments. Samia is especially strong in performance optimization, disaster recovery planning, and Azure database platform support for organizations needing resilient and secure data operations.
