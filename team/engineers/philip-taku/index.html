Professional Overview

Philip is a Senior IAM Engineer and Cybersecurity Professional with 14+ years of experience designing, implementing, and supporting enterprise identity solutions across the automotive and technology industries. He brings extensive expertise in modern identity platforms including Microsoft Entra ID, Okta, and Active Directory, combined with deep knowledge of Zero Trust security principles and regulatory compliance.

Currently at Epsilon (since Nov 2022), Philip leads enterprise identity modernization initiatives, architecting secure authentication systems, implementing passwordless authentication, automating identity lifecycle management, and strengthening access governance across cloud and hybrid environments.

Key Achievements

Enterprise Identity Modernization

Architected enterprise identity solutions using Microsoft Entra ID, Okta, and Active Directory for centralized authentication across cloud and hybrid environments. Migrated legacy identity services to modern platforms supporting hundreds of employees and business partners.

Zero Trust Security Implementation

Designed and implemented Zero Trust access controls using Conditional Access policies, MFA, FIDO2 Security Keys, and risk-based authentication. Strengthened enterprise security posture while maintaining user productivity.

Passwordless Authentication

Implemented enterprise-wide passwordless authentication using FIDO2 Security Keys, WebAuthn, Microsoft Authenticator, and biometric authentication. Reduced password-related security incidents and improved user experience.

Identity Lifecycle Automation

Built automated Joiner-Mover-Leaver (JML) workflows integrated with HR systems. Automated user onboarding, role transitions, license assignment, and deprovisioning, reducing manual administration and improving accuracy.

Privileged Access Management

Implemented PAM solutions with Just-In-Time (JIT) elevation and privileged role governance. Minimized standing administrative privileges and improved audit-ready access controls for regulatory compliance.

Application Federation & Integration

Integrated enterprise applications using SAML 2.0, OAuth 2.0, OpenID Connect, and SCIM protocols. Delivered secure Single Sign-On and automated identity provisioning across cloud and on-premises systems.
