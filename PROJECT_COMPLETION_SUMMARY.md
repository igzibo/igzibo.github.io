## 🚀 Getting Started

### 1. **View the Site Locally**

Python 3:
```bash
cd c:\Users\ryans\code\igzibo.github.io
python -m http.server 8000
# Visit http://localhost:8000
```

Or using Node.js:
```bash
npx http-server
# Visit http://localhost:8080
```

### 2. **Publish to GitHub**

```bash
git add .
git commit -m "Initial Igzibo website with pages and team"
git push origin main
```

Site will be live at: `https://yourusername.github.io` (or your custom domain)

### 3. **Add New Team Members**

See [TEAM_MEMBER_QUICK_ADD.md](TEAM_MEMBER_QUICK_ADD.md) for step-by-step instructions

Quick example:
1. Create folder: `team/engineers/engineer-name/`
2. Copy from: `team/engineers/john-doe/index.html`
3. Update content with engineer info
4. Add card to `team/engineers/index.html`

## ❓ FAQs

**Q: How do I add a new service page?**
A: Create `services/[name]/index.html`, use existing service as template, update links across site.

**Q: How do I change colors?**
A: Edit `assets/css/styles.css`, update CSS variables at the top (--primary, --accent, etc.)

**Q: How do I add a photo to team members?**
A: Create `assets/images/team/` folder, add photos, update `member-photo` div to use `<img>` tag.

**Q: Is there a way to make this dynamic?**
A: See `TEAM_DATA_SAMPLE.js` for example data structure that could be used with a static site generator.

**Q: How often should I update content?**
A: Recommended: Monthly reviews, quarterly major updates, immediately for contact/company info changes.
